# 01 – Excel Data Preparation, Analysis & Dashboard

## 1. Overview

This module covers the Excel-based data preparation, validation, exploratory analysis and dashboard development for the FY2026 Hospital Performance, Quality & Efficiency Analytics project.

The analysis uses a consolidated dataset covering **2,455 US hospitals**, sourced from five CMS hospital performance datasets.

## 2. Data Preparation & Cleaning

- Reviewed and inspected the five original source datasets.
- Standardised column names and data formats.
- Validated hospital facility identifiers and fiscal year.
- Handled missing and unavailable values.
- Integrated the source datasets into a consolidated hospital-level analytical workbook.
- Checked record counts and data consistency.

## 3. Exploratory Data Analysis

Analysed hospital performance across five key areas:

- Total Performance Score (TPS)
- Clinical Outcomes
- Person and Community Engagement
- Patient Safety
- Efficiency and Cost Reduction

## 4. Performance Analysis

- Examined overall hospital performance.
- Compared performance across quality domains.
- Identified variations and performance gaps.
- Evaluated weighted and unweighted domain scores.
- Reviewed score distributions and missing-value patterns.

## 5. Excel Dashboard

Developed an interactive Excel dashboard to present hospital performance indicators and analytical findings.

The dashboard supports clear visual interpretation of overall performance, domain-level results and hospital performance patterns.

## 6. Deliverables

- Cleaned and consolidated hospital dataset.
- Data validation and analytical worksheets.
- Excel calculations and performance analysis.
- Interactive Excel dashboard.

## 7. Tools Used

**Microsoft Excel**

## 8. Module Status

Data preparation, cleaning, exploratory analysis, performance analysis and dashboard development completed.
