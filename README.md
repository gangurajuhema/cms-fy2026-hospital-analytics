# FY2026 Hospital Performance, Quality & Efficiency Analytics

## Project Overview
This project analyses FY2026 hospital performance data to understand differences in hospital quality, clinical outcomes, patient experience, safety, and operational efficiency across 2,455 hospitals.

The objective is to identify performance patterns, evaluate quality measures, and generate meaningful business insights using data analytics tools.

## Business Objectives
- Analyse overall hospital performance.
- Evaluate quality and efficiency across hospital domains.
- Identify performance gaps and variations.
- Compare hospital performance patterns.
- Generate actionable insights to support healthcare decision-making.

## Tools & Technologies
- Microsoft Excel
- SQL Server
- Power BI
- Tableau
- Statistics

## Project Workflow
1. Data Cleaning and Preparation
2. Exploratory Data Analysis
3. SQL-Based Business Analysis
4. Interactive Dashboard Development
5. Statistical Analysis

## Key Analysis Areas
- Hospital Performance Analysis
- Clinical Outcomes
- Patient and Community Engagement
- Patient Safety
- Efficiency and Cost Reduction
- Statistical Relationships and Performance Differences

## Project Status
Excel, SQL Server, Power BI, Tableau, and Statistics analysis completed.

## Dataset
CMS FY2026 Hospital Value-Based Purchasing data, covering 2,455 hospital records.
