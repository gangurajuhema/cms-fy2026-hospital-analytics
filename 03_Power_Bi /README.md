Power BI – FY2026 Hospital Performance, Quality & Efficiency Analytics

1. Project Overview

Developed an interactive Business Intelligence solution using Microsoft Power BI to evaluate hospital performance, quality outcomes, patient experience, safety, and efficiency across 2,455 U.S. hospitals.

The analysis uses five official FY2026 hospital datasets published by the Centers for Medicare & Medicaid Services (CMS). The datasets were cleaned, validated, and consolidated during the Excel data preparation stage before being used for dashboard development.

The objective was to transform hospital-level performance data into meaningful visual insights that support comparative analysis, performance monitoring, and identification of quality-domain strengths and gaps.

2. Data Sources and Integration

Five CMS datasets were used:

- Total Performance Score (TPS)
- Clinical Outcomes
- Person and Community Engagement (HCAHPS)
- Safety
- Efficiency and Cost Reduction

The consolidated dataset contains 2,455 hospital records. The four weighted quality domains—Clinical Outcomes, Person and Community Engagement, Safety, and Efficiency—were analysed alongside the Total Performance Score.

3. Dashboard Development

Developed a three-page interactive Power BI report.

Page 1 – Overall Hospital Performance

- Key performance indicator cards summarising hospital performance.
- Top 10 hospitals by Total Performance Score.
- Bottom 10 hospitals by Total Performance Score.
- Comparison of TPS with weighted quality-domain scores.
- Hospital-level performance comparison table.
- State and Facility ID slicers for interactive filtering.

Page 2 – State Performance

- State-level hospital performance comparisons.
- Analysis of average Total Performance Scores across states.
- Interactive filtering to explore differences in hospital performance by state.

Page 3 – Quality & Efficiency

- Comparative analysis of the four weighted quality domains.
- Examination of hospital-level quality and efficiency patterns.
- Visual analysis to identify variations and performance gaps across domains.

4. Power BI Techniques

- Power Query for data preparation and transformation.
- Data modelling and relationship management.
- DAX measures for analytical calculations and KPIs.
- Interactive slicers and cross-page filtering.
- KPI cards, bar charts, comparison visuals, and tables.
- Dashboard layout, formatting, and visual storytelling.

5. Analytical Objectives

- Evaluate overall hospital performance using TPS.
- Identify hospitals with comparatively high and low performance scores.
- Compare hospital performance across states.
- Examine the contribution and variation of the four weighted quality domains.
- Identify differences between overall performance and individual domain scores.
- Present hospital performance information in an interactive and accessible format.

6. Deliverables

- Three-page interactive Power BI report.
- Hospital-level performance analysis.
- State-level performance comparisons.
- Quality-domain and efficiency analysis.
- Interactive filtering for detailed exploration.

7. Project Status

Power BI Module: Completed
